# 🌐 HTML & CSS Basics — Explained Simply

A beginner-friendly guide to building web pages. **HTML** builds the structure, **CSS** makes it look good. Every lesson is a small file with simple explanations and examples you can open in your browser.

> ⭐ If this repo helps you, give it a star and share it with a friend who is learning web development!

---

## 🧱 HTML vs CSS in one line

- **HTML** = the skeleton (headings, text, images, links, forms)
- **CSS** = the clothes (colors, fonts, spacing, layout)

## ▶️ How to use this repo

1. Download or clone the repo.
2. Double-click any `.html` file — it opens in your browser.
3. Open the same file in a code editor (like [VS Code](https://code.visualstudio.com)), change something, save, and refresh the browser.

💡 Tip: install the **Live Server** extension in VS Code so the page refreshes automatically when you save.

---

## 🧭 Learning tips

- Don't just read — **type the code yourself** and experiment.
- Right click any web page → **Inspect** to see its HTML and CSS.
- After finishing, build your own page (a resume, a blog, a landing page).
